# CalcHub · Автономные калькуляторы

Каждый калькулятор разрабатывается **отдельно** как самодостаточный модуль,
а затем интегрируется в главное приложение CalcHub как вкладка/подвкладка.

## Структура

```
calculators/
  shared/
    base.css           — общая тема (токены, фон, шапка, панели, поля, кнопки)
  <имя-калькулятора>/
    index.html         — разметка (открывается напрямую, без сервера)
    style.css          — стили конкретного калькулятора
    script.js          — логика расчёта
```

## Правила

1. Каждый калькулятор лежит в своей папке и **открывается напрямую**
   двойным кликом по `index.html` (работает через `file://`).
2. Общее оформление берётся из `shared/base.css`; специфика — в локальном
   `style.css`. Скрипты — только локальный `script.js`, без внешних библиотек.
3. Расчёты держим в чистой функции (например, `compute()`), чтобы позже её
   было просто перенести в CalcHub без привязки к DOM.
4. Всё на русском, числа с десятичной запятой (`toLocaleString("ru-RU")`).
5. Проверяем адаптивность (мобильные) и `prefers-reduced-motion`.

## Готовые калькуляторы

- [resistor-color-code](./resistor-color-code/) — цветовая маркировка резисторов (4/5/6 полос)
- [smd-code](./smd-code/) — расшифровка SMD-кодов: резисторы, конденсаторы, индуктивности
- [ohm-law](./ohm-law/) — закон Ома: U, I, R, P — введи любые два
- [number-systems](./number-systems/) — системы счисления (основания 2–36) с пошаговым расчётом
- [bmi](./bmi/) — индекс массы тела с оценкой по возрасту и полу, процент жира, обхват талии
- [valve-shim-calculator](./valve-shim-calculator/) — регулировочные шайбы клапанов (8-клапанные двигатели)
- [graph-plotter](./graph-plotter/) — построитель графиков: точки x/y, несколько зависимостей, авто- и ручной масштаб
